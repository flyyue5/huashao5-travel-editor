# 风格与剪辑判断

这是依据用户选定节目正片视觉方向重新实现的原创包装，不是官方工程、字体或LUT。不依赖失效历史链接或私人文件ID。

## 片头与正片

- 默认片头50秒：0–3秒笑脸/动作/风景钩子，3–7秒原创季名与地点，7–16秒同行者，16–31秒抵达/行走/吃饭/照顾彼此，31–43秒跟音乐推进，43–50秒同框或风景收束并接环境声。实际音乐结构优先于机械秒数。
- 片头从当次原片选镜；换音乐后重新卡点。素材极少时缩短，给正片留新内容。
- 正片按真实事件组织：目标/地点→过程→笑点及反应→结果→风景或情绪收束。不凭字幕制造未发生的冲突。
- 删除误拍、重复、持续失焦和无信息等待；保留理解后文所需上下文、对白后约0.3–1秒反应和2–5秒有意义风景。沉默不等于没价值。
- 硬切依动作、句意和情绪衔接。不每秒切镜，不每次切镜加音效。

## 片尾

- 直接使用正片原有最后一个镜头，默认末尾约3秒出现“下次见”等一句收尾花字。
- 不新增旅行回顾、合照、蒙太奇、独立结束页或音乐，不延长正片、不重复前面的内容。
- 最后约1秒整幅画面（含文字/台标）自然淡黑，现有声音约1.2秒淡出。先让最后一句对白完整结束，不用淡出遮掉尾音。
- 台标沿用用户选择，不另加贴纸或音效；花字不遮脸、不和对白字幕重叠。

## 字幕与花字

- 对白底部蓝→淡紫长条、细米白边、右端小菱形；白色常规字重宋体。每条建议6–22字，长句按句意拆开，不无限缩字号。
- 姓名只用用户提供的身份映射；未知则省略整个姓名签，不写“人物1”。
- 歌词侧面竖排，每组1–14字，逐字轻弹，少量拍点脉冲。横屏默认右侧，竖屏默认左侧避开平台按钮。没核对歌词就省略，不补写。
- 花字用蓝、暖粉、米白小底块、细线和星点，短句随动作出现。不杜撰人物内心话。
- 标题、地点、结尾也用装饰文字，避免对白/歌词/标题同时挤满画面。

## 贴纸与台标

- 原创图集：0海鸥、1小狗、2球、3爱心、4餐盘、5旅行箭头。跟随对应动作短暂轻弹、淡出，不常驻角落。
- 台标可选无、文字频道名、用户透明PNG；文字蓝边或金边，小尺寸左上安全区常驻，硬切时连续。
- 不包含个人频道台标、节目台标、水印、账号兔子或平台尾页。

## 色彩与声音

- 先处理曝光/白平衡/HDR，再轻量使用natural_warm等预设；默认none。不把二次上传偏色当官方滤镜。
- 14首试听为固定候选库。听后结合画面选择，不仅凭歌名断言情绪。单cue使用实际可用长度，不改变音高速度、不循环补长。
- 原版片头优先；正片音乐适时进入、渐入渐出、对白避让，保留纯现场声段。
- 原创轻弹、回弹、轻铃、快门、轻扫仅跟随有效动作，检查是否盖住字头。
- 默认目标约-16 LUFS、真峰值≤-1.5 dBTP，响度通过仍需听审。
