# 验收

逐项记录passed / failed / pending和实际证据，未执行不能写通过。

1. 技术：完整解码无错误，实际片长符合EDL，宽高方向正确、音轨存在、无黑闪截断。qa不证明故事或语音正确。
2. 字幕：各类别抽帧并连续看对白段，无缺字截字小字，时码一致，长句分段，姓名仅用用户映射。
3. 歌词：侧面竖排轻跳、首尾字不越界；未核实歌词就省略。
4. 画面：裁切、肤色、HDR代理、台标与字幕安全区；贴纸不挡脸，无水印/平台尾页/兔子。
5. 听审：完整听一遍，原声清楚、BGM适时进出、音效不抢字头、无突响断尾，片头无变调变速。
6. 故事：连续观看，笑点上下文完整、不颠倒事实、不制造对白、不凑时长。
7. 片尾：仅原有末镜头加花字并渐隐，镜头数量与片长不变，没有回顾/合照等重复镜头；正片字幕和原有音轨时码不变，完整话尾后再渐弱。
8. 交付：原片未变，使用新输出名，MP4/字幕/时间线一致，曲目区间有记录。浏览器检查必须实际播放。

示例：技术解码已通过，字幕抽帧已检查，完整听审待完成。不要用“全部验证通过”概括局部检查。
